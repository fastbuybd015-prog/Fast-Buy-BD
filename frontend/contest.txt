# E-Commerce Website — Full Frontend Implementation Task

You are acting as a **senior product engineer, UI/UX designer, frontend architect, and interaction designer** responsible for building a polished university-level e-commerce project.

Your job is to **fully implement the project inside the existing codebase**, not just provide suggestions or partial code.

Do not wait for me to specify every small detail. Use the requirements below as the product brief, make sensible professional decisions yourself, and complete the implementation end-to-end.

The goal is a **clean, modern, premium-looking e-commerce website inspired by the usability and visual quality of established Bangladeshi e-commerce platforms such as Shwapno**, while creating an original design rather than copying any existing website.

---

## 1. PROJECT GOAL

Build a frontend-first e-commerce website where users can:

- Browse products
- Browse products by menu/category
- See discounted products
- See which shop/store a product belongs to
- Open a product details page
- Select quantity
- Add products to cart
- Review cart
- Place a demo order
- Register / Login through a demo UI
- See a 1-day trial subscription concept
- After the trial expires, see an option to subscribe for **৳50/month**

This is primarily a **frontend project/demo**.

Do NOT over-engineer the backend.

The website should feel like a real product, but most data and functionality can use local mock data and frontend state.
